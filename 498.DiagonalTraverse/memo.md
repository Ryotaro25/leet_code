Input: mat = [[(0,0),(0,1),(0,2)],[(1,0),(1,1),(1,2)],[(2,0),(2,1),(2,2)]]
Output: [(0,0),(0,1),(1,0),(2,0),(1,1),(0,2),(1,2),(2,1),(2,2)]

Outputに関してよりわかりやすく
Output:
(0,0),             // 左から右
(0,1),(1,0),       // 右から左
(2,0),(1,1),(0,2), // 左から右
(1,2),(2,1),       // 右から左
(2,2)              // 左から右

indexの合計が同じものでまとめることが出来る
indexの合計が偶数の場合は左から右に探索し、奇数の場合は右から左に探索する
